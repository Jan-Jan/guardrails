## What was wrong, and what was built

`grill-requirements` shipped sequential ADR names, `docs/adr/NNNN-slug.md`,
which clash across branches, and this repository named its ADRs by date. An
ADR is now an item with a random ID, `**ADR-<token>**:`, in
`docs/adr/ADR-<token>-<slug>.md`. `templates/config.yaml` declares `ADR`, so
`new-id.sh` mints it and `check-ids.sh` checks it; T1 measured that no script
change was needed. The ratchet upgrade note states what declaring `ADR`
changes in a project with existing ADRs.
