# Requirements: history citations

**REQ-2jdxu5**: The software shall report HISTORY-CITATION, and fail, for each line of a ledger, strict_paths or test_paths file that names a dated file under docs/plans/ or docs/verification/.

**REQ-rn6cxw**: The software shall report no HISTORY-CITATION for a file inside a docs/plans/ or docs/verification/ directory.
